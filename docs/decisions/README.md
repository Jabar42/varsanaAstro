# Architecture Decision Records

Lightweight decision log for this project. Each file is a standalone ADR.

## Format

```markdown
# ADR-NNN: Short title

**Date:** YYYY-MM-DD
**Status:** proposed | accepted | deprecated | superseded

## Context
## Decision
## Consequences
```

## Creating a new ADR

Copy the template, increment the number, and write it up. Keep it short — a few
paragraphs each. The goal is to record _why_ a decision was made, not to
document the implementation.
